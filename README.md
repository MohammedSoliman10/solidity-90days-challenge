# Solidity 90 Days Challenge 
My daily journey learning Solidity and Web3 development — one day, one commit, one step closer to becoming a blockchain developer.
## About This Challenge
90 days of consistent, public learning covering blockchain fundamentals, Solidity smart contract development, and the broader Web3 ecosystem — from writing my first contract in Remix to building and testing with Foundry.

| 19  | Solidity data types deep dive — `address`, `string`, `uint`, `bytes` |

| 21  | Global Variables — `block.timestamp`, `block.number`, `msg.sender`, `msg.value`, `tx.origin` vs `msg.sender` |
| 22  | Control flow — `if/else` (with `getGrade` example), `for` loops, `while` loops |
